# Nextra 4

O [Nextra 4](https://nextra.site) é um site de documentação criado usando [Next.js](https://nextjs.org), [MDX](https://mdxjs.com), e [Tailwind CSS](https://tailwindcss.com). Ele transforma arquivos Markdown e MDX em páginas totalmente estruturadas, com navegação automática, sidebar dinâmica, pesquisa integrada e temas prontos para uso.

## Primeiros Passos

O primeiro passo é clonar o projeto Nextra com o comando git:

```bash
git clone https://github.com/LeoCassiniScardini/tcc-nextra/.git
```
O próximo passo é instalar os pacotes Node usando o gerenciador de pacotes:

```bash
pnpm install
# ou
npm install
```

Por fim, execute o servidor de desenvolvimento:

```bash
pnpm dev
# ou
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador e veja o resultado.
