# «SubCollectionOf»

A relação «SubCollectionOf» representa uma relação parte-todo entre dois coletivos. Ela deve ser usada quando uma coleção menor é parte de uma coleção maior.

## Exemplos simples:

- Turma A -- «SubCollectionOf» -- Conjunto de Turmas
- Equipe Técnica -- «SubCollectionOf» -- Comissão Geral
- Frota de Ônibus -- «SubCollectionOf» -- Frota Municipal
- Grupo de Professores -- «SubCollectionOf» -- Corpo Docente
- Coleção de Cartas Curinga -- «SubCollectionOf» -- Baralho

A documentação da OntoUML define «SubCollectionOf» como uma relação de parte-todo entre dois «Collective». Exemplos clássicos incluem a coleção de curingas como parte de um baralho, a coleção de garfos como parte de um conjunto de talheres e a coleção de homens como parte de uma multidão.

## Categorias principais

| Propriedade | Valor |
|---|---|
| Categoria | Relação parte-todo |
| Tipo de parte | Collective |
| Tipo de todo | Collective |
| Direcionada | Sim |
| Origem típica | Subcoletivo |
| Destino típica | Coletivo maior |
| Multiplicidade da origem | 1..1 |
| Multiplicidade do destino | 1..1 |
| Transitividade | Sim |
| Compartilhável | Pode ser compartilhável ou não compartilhável |
| Exemplo típico | Frota de Ônibus–Frota Municipal |

## Definição

Uma relação «SubCollectionOf» deve ser usada quando tanto a parte quanto o todo são coletivos.

### Exemplo:

```
«Collective» Frota de Ônibus
«Collective» Frota Municipal

Frota de Ônibus -- «SubCollectionOf» -- Frota Municipal
```

- A Frota de Ônibus é uma coleção de veículos.
- A Frota Municipal também é uma coleção de veículos.
- Logo, a relação entre elas é de subcoleção.

### Outro exemplo:

```
«Collective» Grupo de Professores
«Collective» Corpo Docente

Grupo de Professores -- «SubCollectionOf» -- Corpo Docente
```

- O Grupo de Professores é um coletivo menor dentro do Corpo Docente.

## Diferença entre SubCollectionOf, MemberOf e ComponentOf

### SubCollectionOf

Usado quando a parte também é um coletivo.

```
Frota de Ônibus -- «SubCollectionOf» -- Frota Municipal
```

### MemberOf

Usado quando a parte é um indivíduo membro de um coletivo.

```
Ônibus -- «MemberOf» -- Frota de Ônibus
```

### ComponentOf

Usado quando a parte é um componente funcional de um todo funcional.

```
Motor -- «ComponentOf» -- Ônibus
```

A diferença principal é:

- **MemberOf** = indivíduo → coletivo
- **SubCollectionOf** = coletivo → coletivo
- **ComponentOf** = componente funcional → todo funcional

## Restrições

A principal restrição é que os dois extremos da relação devem ser coletivos. A documentação indica que as classes conectadas aos dois lados de «SubCollectionOf» devem representar universais cujas instâncias são «Collective».

### Exemplo correto:

```
«Collective» Turma do 1º Ano
«Collective» Conjunto de Turmas da Escola

Turma do 1º Ano -- «SubCollectionOf» -- Conjunto de Turmas da Escola
```

### Exemplo inadequado:

```
Aluno -- «SubCollectionOf» -- Turma
```

Nesse caso, Aluno é membro da turma, não subcoleção. O correto seria:

```
Aluno -- «MemberOf» -- Turma
```

### Outro exemplo inadequado:

```
Motor -- «SubCollectionOf» -- Carro
```

Motor não é coletivo. É componente funcional do carro. O correto seria:

```
Motor -- «ComponentOf» -- Carro
```

## Transitividade

A relação «SubCollectionOf» é transitiva. Isso significa que, se um coletivo A é subcoleção de B, e B é subcoleção de C, então A também é subcoleção de C.

### Exemplo:

```
Equipe de Professores da Educação Infantil
    -- «SubCollectionOf» --
Corpo Docente da Educação Infantil
    -- «SubCollectionOf» --
Corpo Docente da Escola
```

Logo, a equipe de professores da educação infantil também é subcoleção do corpo docente da escola.

## Compartilhamento

A relação «SubCollectionOf» pode ser compartilhável ou não compartilhável, dependendo do domínio. A documentação exemplifica que um mesmo grupo de irmãos pode ser subcoleção de uma família, de um time de futebol e de uma unidade de bombeiros voluntários.

### Exemplo compartilhável:

```
«Collective» Grupo de Servidores
«Collective» Comissão de Licitação
«Collective» Equipe de Planejamento

Grupo de Servidores -- «SubCollectionOf» -- Comissão de Licitação
Grupo de Servidores -- «SubCollectionOf» -- Equipe de Planejamento
```

- O mesmo grupo pode integrar mais de um coletivo, se isso fizer sentido no domínio.

### Exemplo não compartilhável:

```
«Collective» Diretório Municipal de Partido
«Collective» Partido Político

Diretório Municipal -- «SubCollectionOf» -- Partido Político
```

- Nesse caso, regras institucionais podem impedir que o mesmo diretório seja parte de mais de um partido.

## Questões comuns

### Qual é a diferença entre membro e subcoleção?

O membro é um indivíduo.
A subcoleção é também um coletivo.

**Exemplo:**

```
Aluno -- «MemberOf» -- Turma
Grupo de Alunos -- «SubCollectionOf» -- Turma
```

- Aluno é membro da turma.
- Grupo de Alunos é uma subcoleção dentro da turma.

### Quando devo usar SubCollectionOf?

Use quando estiver modelando uma relação como:

- grupo dentro de grupo
- equipe dentro de comissão
- subfrota dentro de frota
- conjunto de alunos dentro de turma
- coleção de cartas dentro de baralho

### Toda parte de um coletivo é SubCollectionOf?

Não. Se a parte for um indivíduo, use «MemberOf».

**Exemplo:**

```
Servidor -- «MemberOf» -- Comissão
```

Se a parte também for um coletivo, use «SubCollectionOf».

```
Equipe Técnica -- «SubCollectionOf» -- Comissão
```

### Uma subcoleção precisa mudar a identidade do coletivo maior?

Não necessariamente. A documentação explica que a adição ou remoção de uma subcoleção, ou até de membros, pode ou não alterar a identidade do coletivo. Por isso, os coletivos são tratados como intencionais, e não puramente extensionais.

## Exemplos

### Exemplo 1 — Escola
```
«Collective» Grupo de Alunos da Educação Infantil
«Collective» Corpo Discente da Escola

Grupo de Alunos da Educação Infantil -- «SubCollectionOf» -- Corpo Discente da Escola
```

- O grupo de alunos da educação infantil é uma subcoleção do corpo discente.

### Exemplo 2 — Administração pública
```
«Collective» Equipe de Manutenção
«Collective» Equipe da Secretaria de Educação

Equipe de Manutenção -- «SubCollectionOf» -- Equipe da Secretaria de Educação
```

- A equipe de manutenção é um coletivo menor dentro de um coletivo maior.

### Exemplo 3 — Frota
```
«Collective» Frota de Ambulâncias
«Collective» Frota Municipal

Frota de Ambulâncias -- «SubCollectionOf» -- Frota Municipal
```

- A frota de ambulâncias é uma subcoleção da frota municipal.

### Exemplo 4 — Baralho
```
«Collective» Cartas Curinga
«Collective» Baralho

Cartas Curinga -- «SubCollectionOf» -- Baralho
```

- A coleção de curingas é uma subcoleção dentro do baralho.

## Resumo final

A relação «SubCollectionOf» deve ser usada para representar uma relação parte-todo entre dois coletivos. Ela é adequada para casos como Frota de Ônibus–Frota Municipal, Equipe Técnica–Comissão, Grupo de Alunos–Turma e Cartas Curinga–Baralho. Use «MemberOf» quando a parte for um indivíduo e «ComponentOf» quando a parte for componente funcional de um todo.
