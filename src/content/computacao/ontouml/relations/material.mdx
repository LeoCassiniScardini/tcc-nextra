# «Material»

A relação «Material» representa uma relação com conteúdo próprio, normalmente social, jurídica, institucional, administrativa ou funcional, que não existe apenas por comparação direta entre indivíduos.

Ela é diferente da relação «Formal» porque a relação material precisa ser explicada por um relator. Ou seja, existe alguma entidade relacional que fundamenta a ligação entre as partes.

## Exemplos simples:

- Pessoa trabalha para Empresa
- Pessoa está matriculada em Escola
- Pessoa é casada com Pessoa
- Paciente é tratado por Unidade de Saúde
- Segurado recebe Benefício Previdenciário

A documentação da OntoUML explica que relações materiais possuem estrutura material própria e são mediadas por indivíduos chamados «Relator», como emprego, matrícula, casamento, tratamento ou compromisso.

## Categorias principais

| Propriedade | Valor |
|---|---|
| Categoria | Relação material |
| Direcionada | Não |
| Multiplicidade da origem | 1..* |
| Multiplicidade do destino | 1..* |
| Depende de Relator | Sim |
| Relação derivada | Sim |
| Relação auxiliar típica | «Derivation» |
| Relações relacionadas | «Mediation», «Derivation», «Relator» |
| Exemplo típico | trabalha para, estuda em, é casado com, recebe benefício |

## Definição

Uma relação «Material» deve ser usada quando a associação entre os indivíduos precisa de uma entidade intermediária que explique por que a relação existe.

### Exemplo:

```
«Kind» Pessoa
«Kind» Empresa
«Relator» Contrato de Trabalho

Pessoa -- «Material» trabalha para -- Empresa
Contrato de Trabalho -- «Derivation» -- trabalha para
Pessoa -- «Mediation» -- Contrato de Trabalho
Empresa -- «Mediation» -- Contrato de Trabalho
```

A pessoa não "trabalha para" a empresa apenas por comparação de propriedades. Essa relação existe porque há um vínculo, contrato ou relação de emprego que conecta as partes.

## Relação com «Relator»

O «Relator» é a entidade que fundamenta a relação material. A documentação define o «Relator» como o elemento que funciona como "truth-maker" das relações materiais, isto é, aquilo que precisa existir para que dois ou mais indivíduos estejam conectados por uma relação material.

### Exemplo:

```
«Kind» Pessoa
«Kind» Escola
«Relator» Matrícula

Pessoa -- «Material» estuda em -- Escola
Matrícula -- «Derivation» -- estuda em
Pessoa -- «Mediation» -- Matrícula
Escola -- «Mediation» -- Matrícula
```

A matrícula é o relator que justifica a relação material estuda em.

## Restrições

Toda relação «Material» deve estar ligada a exatamente uma relação «Derivation», que aponta para o «Relator» que fundamenta aquela relação. Além disso, a relação material deve ser derivada das mediações entre o relator e os participantes.

### Exemplo correto:

```
«Relator» Casamento

Pessoa -- «Material» é casada com -- Pessoa
Casamento -- «Derivation» -- é casada com
Pessoa -- «Mediation» -- Casamento
Pessoa -- «Mediation» -- Casamento
```

### Exemplo incompleto:

```
Pessoa -- «Material» é casada com -- Pessoa
```

Nesse caso, falta indicar o «Relator» Casamento, que fundamenta a relação.

Outra restrição importante é que as cardinalidades da relação material são derivadas das relações de «Mediation». A documentação explica que as restrições de cardinalidade das mediações "colapsam" na relação material derivada.

## Diferença entre Material e Formal

A diferença principal é a existência ou não de um «Relator».

- «Formal» → relação direta, normalmente comparativa
- «Material» → relação fundamentada por um relator

### Exemplo de relação formal:

```
Pessoa -- «Formal» é mais velha que -- Pessoa
```

A relação depende apenas da comparação entre idades.

### Exemplo de relação material:

```
Pessoa -- «Material» trabalha para -- Empresa
```

Essa relação depende de um vínculo de trabalho, contrato ou emprego.

A documentação da OntoUML distingue relações formais, que conectam entidades diretamente, de relações materiais, que possuem estrutura própria e são mediadas por relatores.

## Questões comuns

### Toda relação social ou jurídica é Material?

Na maioria dos casos, sim. Relações como casamento, emprego, matrícula, contrato, benefício, tratamento médico e vínculo administrativo geralmente dependem de um «Relator».

**Exemplos:**

- Pessoa é casada com Pessoa → Relator: Casamento
- Pessoa trabalha para Empresa → Relator: Contrato de Trabalho
- Pessoa estuda em Escola → Relator: Matrícula
- Pessoa recebe Benefício → Relator: Benefício Previdenciário

### Qual é a diferença entre a relação material e o relator?

- A relação material é a ligação derivada entre os participantes.
- O relator é a entidade que fundamenta essa ligação.

**Exemplo:**

```
Relação material: Pessoa trabalha para Empresa
Relator: Contrato de Trabalho
```

O contrato ou vínculo de trabalho explica por que aquela pessoa trabalha para aquela empresa.

### Uma mesma relação material pode vir de mais de um relator?

Na modelagem OntoUML, cada relação «Material» deve ser conectada a exatamente uma relação «Derivation». Porém, um mesmo «Relator» pode derivar várias relações materiais.

**Exemplo:**

```
«Relator» Contrato de Prestação de Serviço

Pessoa -- «Material» presta serviço para -- Empresa
Empresa -- «Material» contrata -- Pessoa
```

As duas relações podem ser derivadas do mesmo contrato.

### Quando não devo usar Material?

Não use «Material» quando a relação for apenas comparativa ou formal.

**Exemplo inadequado:**

```
Produto -- «Material» é mais caro que -- Produto
```

O correto seria:

```
Produto -- «Formal» é mais caro que -- Produto
```

porque a relação depende da comparação entre preços, e não de um relator.

## Exemplos

### Exemplo 1 — Casamento
```
«Kind» Pessoa
«Relator» Casamento

Pessoa -- «Material» é casada com -- Pessoa
Casamento -- «Derivation» -- é casada com
Pessoa -- «Mediation» -- Casamento
Pessoa -- «Mediation» -- Casamento
```

- A relação é casada com é material porque depende do relator Casamento.

### Exemplo 2 — Educação
```
«Kind» Pessoa
«Kind» Escola
«Relator» Matrícula

Pessoa -- «Material» estuda em -- Escola
Matrícula -- «Derivation» -- estuda em
Pessoa -- «Mediation» -- Matrícula
Escola -- «Mediation» -- Matrícula
```

- A pessoa estuda na escola porque existe uma matrícula que conecta os dois.

### Exemplo 3 — Trabalho
```
«Kind» Pessoa
«Kind» Empresa
«Relator» Contrato de Trabalho

Pessoa -- «Material» trabalha para -- Empresa
Contrato de Trabalho -- «Derivation» -- trabalha para
Pessoa -- «Mediation» -- Contrato de Trabalho
Empresa -- «Mediation» -- Contrato de Trabalho
```

- A relação de trabalho é material porque depende do contrato ou vínculo laboral.

### Exemplo 4 — Direito previdenciário
```
«Kind» Pessoa
«Kind» INSS
«Relator» Benefício Previdenciário

Pessoa -- «Material» recebe benefício de -- INSS
Benefício Previdenciário -- «Derivation» -- recebe benefício de
Pessoa -- «Mediation» -- Benefício Previdenciário
INSS -- «Mediation» -- Benefício Previdenciário
```

- A relação entre beneficiário e INSS é material porque é fundamentada pelo benefício previdenciário.

## Resumo final

A relação «Material» deve ser usada para representar relações com conteúdo próprio, especialmente relações sociais, jurídicas, administrativas, institucionais ou funcionais. Ela sempre depende de um «Relator», é derivada por «Derivation» e se apoia em relações de «Mediation». Exemplos comuns são trabalha para, estuda em, é casado com, recebe benefício de, é tratado por e contrata.
