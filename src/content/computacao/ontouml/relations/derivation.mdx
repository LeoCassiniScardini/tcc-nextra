# «Derivation»

A relação «Derivation» conecta um «Relator» a uma relação «Material» derivada dele.

Ela serve para mostrar que uma relação material entre participantes só existe porque há um relator que a fundamenta.

## Exemplos simples:

- Contrato -- «Derivation» -- trabalha para
- Matrícula -- «Derivation» -- estuda em
- Casamento -- «Derivation» -- é casado com
- Benefício Previdenciário -- «Derivation» -- recebe benefício de
- Contrato de Locação -- «Derivation» -- aluga de

Em termos práticos:

- «Relator» explica por que a relação existe
- «Derivation» liga o relator à relação material
- «Material» liga diretamente os participantes

## Categorias principais

| Propriedade | Valor |
|---|---|
| Categoria | Relação entre Relator e Material |
| Tipo de relação | Metarrelacional / derivação |
| Origem típica | Relator |
| Destino típico | Relação Material |
| Depende de Relator | Sim |
| Relações relacionadas | Material, Mediation, Relator |
| Função principal | Indicar que uma relação material deriva de um relator |
| Exemplo típico | Contrato deriva trabalha para |

## Definição

Uma relação «Derivation» deve ser usada quando se quer explicitar que uma relação «Material» é derivada de um «Relator».

Nesse exemplo:

- Contrato de Trabalho é o relator;
- Pessoa e Empresa participam do contrato por «Mediation»;
- a relação trabalha para é uma relação «Material»;
