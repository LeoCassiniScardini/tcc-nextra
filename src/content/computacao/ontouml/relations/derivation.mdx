# «Derivation»

A relação «Derivation» conecta um «Relator» a uma relação «Material» derivada dele.

Ela serve para mostrar que uma relação material entre participantes só existe porque há um relator que a fundamenta.

## Exemplos simples:

- Contrato -- «Derivation» -- trabalha para
- Matrícula -- «Derivation» -- estuda em
- Casamento -- «Derivation» -- é casado com
- Benefício Previdenciário -- «Derivation» -- recebe benefício de
- Contrato de Locação -- «Derivation» -- aluga de

Em termos práticos:

- «Relator» explica por que a relação existe
- «Derivation» liga o relator à relação material
- «Material» liga diretamente os participantes

## Categorias principais

| Propriedade | Valor |
|---|---|
| Categoria | Relação entre Relator e Material |
| Tipo de relação | Metarrelacional / derivação |
| Origem típica | Relator |
| Destino típico | Relação Material |
| Depende de Relator | Sim |
| Relações relacionadas | Material, Mediation, Relator |
| Função principal | Indicar que uma relação material deriva de um relator |
| Exemplo típico | Contrato deriva trabalha para |

## Definição

Uma relação «Derivation» deve ser usada quando se quer explicitar que uma relação «Material» é derivada de um «Relator».

### Exemplo:

```
«Kind» Pessoa
«Kind» Empresa
«Relator» Contrato de Trabalho

Pessoa -- «Material» trabalha para -- Empresa

Pessoa -- «Mediation» -- Contrato de Trabalho
Empresa -- «Mediation» -- Contrato de Trabalho

Contrato de Trabalho -- «Derivation» -- trabalha para
```

Nesse exemplo:

- Contrato de Trabalho é o relator;
- Pessoa e Empresa participam do contrato por «Mediation»;
- a relação trabalha para é uma relação «Material»;
- a «Derivation» mostra que trabalha para deriva do Contrato de Trabalho.

## Estrutura típica

A estrutura mais comum envolvendo «Derivation» é:

```
Participante A -- «Mediation» -- Relator
Participante B -- «Mediation» -- Relator

Participante A -- «Material» -- Participante B

Relator -- «Derivation» -- Material
```

### Exemplo:

```
Pessoa -- «Mediation» -- Matrícula
Escola -- «Mediation» -- Matrícula

Pessoa -- «Material» estuda em -- Escola

Matrícula -- «Derivation» -- estuda em
```

A Matrícula fundamenta a relação material estuda em.

## Restrições

A relação «Derivation» deve envolver:

- um «Relator»
- uma relação «Material»

### Exemplo correto:

```
«Relator» Casamento

Pessoa -- «Material» é casada com -- Pessoa

Casamento -- «Derivation» -- é casada com
```

### Exemplo inadequado:

```
Pessoa -- «Derivation» -- trabalha para
```

Pessoa não é um relator. Portanto, não deve ser origem da derivação.

### Outro exemplo inadequado:

```
Contrato -- «Derivation» -- mais velho que
```

Mais velho que é uma relação formal, não material. Portanto, não deve ser derivada de um relator.

## Relação com Mediation

A «Derivation» não substitui a «Mediation».

Elas têm funções diferentes:

- «Mediation» → conecta o relator aos participantes
- «Derivation» → conecta o relator à relação material derivada

### Exemplo completo:

```
«Kind» Pessoa
«Kind» Banco
«Relator» Conta Bancária

Pessoa -- «Mediation» -- Conta Bancária
Banco -- «Mediation» -- Conta Bancária

Pessoa -- «Material» possui conta em -- Banco

Conta Bancária -- «Derivation» -- possui conta em
```

- Sem as mediações, não fica claro quem participa do relator.
- Sem a derivação, não fica claro de qual relator a relação material deriva.

## Questões comuns

### Qual é a diferença entre Derivation e Mediation?

- A «Mediation» liga o relator aos participantes.
- A «Derivation» liga o relator à relação material.

**Exemplo:**

```
Pessoa -- «Mediation» -- Contrato
Empresa -- «Mediation» -- Contrato

Contrato -- «Derivation» -- trabalha para
```

### Toda relação material precisa de derivation?

Sim. Na OntoUML, uma relação «Material» deve ser derivada de um «Relator». A «Derivation» serve para explicitar essa fundamentação.

**Exemplo:**

```
Pessoa -- «Material» estuda em -- Escola
Matrícula -- «Derivation» -- estuda em
```

### Toda relação formal precisa de derivation?

Não. Relações formais não dependem de relator.

**Exemplo:**

```
Pessoa -- «Formal» mais velha que -- Pessoa
```

Essa relação pode ser explicada pela comparação entre idades, sem precisar de «Relator» e sem «Derivation».

### Um mesmo relator pode derivar mais de uma relação material?

Sim.

**Exemplo:**

```
«Relator» Contrato de Prestação de Serviço

Prestador -- «Material» presta serviço para -- Contratante
Contratante -- «Material» contrata -- Prestador

Contrato de Prestação de Serviço -- «Derivation» -- presta serviço para
Contrato de Prestação de Serviço -- «Derivation» -- contrata
```

O mesmo contrato pode fundamentar mais de uma leitura da relação entre as partes.

### Uma relação material pode derivar de mais de um relator?

Em regra, a relação material deve ter sua derivação claramente vinculada a um relator específico. Se houver mais de uma base relacional possível, normalmente é melhor modelar relatores distintos ou relações materiais distintas.

**Exemplo:**

```
Contrato de Trabalho -- «Derivation» -- trabalha para
Contrato de Prestação de Serviço -- «Derivation» -- presta serviço para
```

Isso evita ambiguidade no modelo.

## Exemplos

### Exemplo 1 — Contrato de trabalho
```
«Kind» Pessoa
    «Role» Empregado

«Kind» Empresa
    «Role» Empregador

«Relator» Contrato de Trabalho

Empregado -- «Mediation» -- Contrato de Trabalho
Empregador -- «Mediation» -- Contrato de Trabalho

Empregado -- «Material» trabalha para -- Empregador

Contrato de Trabalho -- «Derivation» -- trabalha para
```

- O contrato de trabalho fundamenta a relação material entre empregado e empregador.

### Exemplo 2 — Matrícula escolar
```
«Kind» Pessoa
    «Role» Aluno

«Kind» Escola
«Relator» Matrícula

Aluno -- «Mediation» -- Matrícula
Escola -- «Mediation» -- Matrícula

Aluno -- «Material» estuda em -- Escola

Matrícula -- «Derivation» -- estuda em
```

- A matrícula fundamenta a relação entre aluno e escola.

### Exemplo 3 — Casamento
```
«Kind» Pessoa
    «Role» Cônjuge

«Relator» Casamento

Cônjuge -- «Mediation» -- Casamento
Cônjuge -- «Mediation» -- Casamento

Cônjuge -- «Material» é casado com -- Cônjuge

Casamento -- «Derivation» -- é casado com
```

- O casamento fundamenta a relação conjugal.

### Exemplo 4 — Direito previdenciário
```
«Kind» Pessoa
    «Role» Beneficiário

«Kind» INSS

«Relator» Benefício Previdenciário

Beneficiário -- «Mediation» -- Benefício Previdenciário
INSS -- «Mediation» -- Benefício Previdenciário

Beneficiário -- «Material» recebe benefício de -- INSS

Benefício Previdenciário -- «Derivation» -- recebe benefício de
```

- O benefício previdenciário fundamenta a relação jurídica entre beneficiário e INSS.

## Resumo final

A relação «Derivation» deve ser usada para indicar que uma relação «Material» deriva de um «Relator». Ela não liga diretamente os participantes entre si, nem substitui a «Mediation». Sua função é mostrar a fundamentação ontológica da relação material, como em Contrato → trabalha para, Matrícula → estuda em, Casamento → é casado com ou Benefício Previdenciário → recebe benefício de.
