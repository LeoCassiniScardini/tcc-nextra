# «MemberOf»

A relação «MemberOf» representa uma relação parte-todo entre um indivíduo e um coletivo. Ela deve ser usada quando uma entidade é membro de uma coleção, grupo, turma, equipe, frota, rebanho ou outro «Collective».

## Exemplos simples:

- Aluno -- «MemberOf» -- Turma
- Servidor -- «MemberOf» -- Equipe
- Veículo -- «MemberOf» -- Frota
- Animal -- «MemberOf» -- Rebanho
- Árvore -- «MemberOf» -- Floresta

Em termos práticos:

- «MemberOf» = indivíduo membro de um coletivo

## Categorias principais

| Propriedade | Valor |
|---|---|
| Categoria | Relação parte-todo |
| Tipo de todo | Collective |
| Tipo de parte | Membro individual |
| Direcionada | Sim |
| Origem típica | Indivíduo membro |
| Destino típica | Coletivo |
| Reflexiva | Não |
| Simétrica | Não |
| Transitiva | Não necessariamente |
| Cíclica | Não |
| Exemplos típicos | Aluno–Turma, Veículo–Frota, Animal–Rebanho |

## Definição

Uma relação «MemberOf» deve ser usada quando uma entidade individual participa de um todo coletivo como membro.

### Exemplo:

```
«Kind» Aluno
«Collective» Turma

Aluno -- «MemberOf» -- Turma
```

- O Aluno é membro da Turma.
- A Turma é um coletivo formado por alunos.

### Outro exemplo:

```
«Kind» Veículo
«Collective» Frota

Veículo -- «MemberOf» -- Frota
```

- O Veículo é membro da Frota.
- A Frota é um coletivo de veículos.

## Diferença entre MemberOf, ComponentOf e SubCollectionOf

### MemberOf

Usado quando uma entidade individual é membro de um coletivo.

```
Aluno -- «MemberOf» -- Turma
```

### ComponentOf

Usado quando uma parte exerce função dentro de um todo funcional.

```
Motor -- «ComponentOf» -- Carro
```

### SubCollectionOf

Usado quando um coletivo menor é parte de um coletivo maior.

```
Pelotão -- «SubCollectionOf» -- Exército
```

A diferença central é:

- **MemberOf** = indivíduo → coletivo
- **SubCollectionOf** = coletivo → coletivo
- **ComponentOf** = componente funcional → todo funcional

## Restrições

A relação «MemberOf» deve ter como todo uma entidade coletiva, normalmente estereotipada como «Collective».

### Exemplo correto:

```
«Kind» Pessoa
«Collective» Família

Pessoa -- «MemberOf» -- Família
```

### Exemplo inadequado:

```
Motor -- «MemberOf» -- Carro
```

Nesse caso, Motor não é membro de um coletivo. Ele é componente funcional de um carro. O adequado seria:

```
Motor -- «ComponentOf» -- Carro
```

### Outro exemplo inadequado:

```
Areia -- «MemberOf» -- Praia
```

Areia não é membro individual de uma coleção. Se o foco for quantidade de matéria, o adequado seria modelar como «Quantity» e avaliar o uso de «SubQuantityOf».

## Questões comuns

### Qual é a diferença entre membro e componente?

O membro participa de um coletivo como uma unidade semelhante às demais.

```
Aluno -- «MemberOf» -- Turma
```

O componente exerce função dentro de um todo funcional.

```
Motor -- «ComponentOf» -- Carro
```

O aluno não é "componente funcional" da turma no mesmo sentido em que o motor é componente do carro. Ele é membro do coletivo.

### Todo grupo usa MemberOf?

Sim, quando o grupo for modelado como «Collective» e seus integrantes forem membros individualizáveis.

**Exemplos:**

- Pessoa -- «MemberOf» -- Grupo de Trabalho
- Aluno -- «MemberOf» -- Turma
- Servidor -- «MemberOf» -- Comissão
- Veículo -- «MemberOf» -- Frota

### Uma pessoa pode ser membro de vários coletivos?

Sim.

**Exemplo:**

```
Pessoa -- «MemberOf» -- Família
Pessoa -- «MemberOf» -- Equipe
Pessoa -- «MemberOf» -- Comissão
```

A mesma pessoa pode participar de diferentes coletivos, dependendo do domínio.

### Quando usar SubCollectionOf em vez de MemberOf?

Use «SubCollectionOf» quando a parte também for um coletivo.

**Exemplo:**

```
«Collective» Turma
«Collective» Escola como Conjunto de Turmas

Turma -- «SubCollectionOf» -- Escola como Conjunto de Turmas
```

Use «MemberOf» quando a parte for um indivíduo membro:

```
Aluno -- «MemberOf» -- Turma
```

## Exemplos

### Exemplo 1 — Turma escolar
```
«Kind» Aluno
«Collective» Turma

Aluno -- «MemberOf» -- Turma
```

- A turma é composta por alunos individualizáveis.

### Exemplo 2 — Frota
```
«Kind» Veículo
«Collective» Frota

Veículo -- «MemberOf» -- Frota
```

- A frota é um coletivo de veículos.

### Exemplo 3 — Rebanho
```
«Kind» Animal
«Collective» Rebanho

Animal -- «MemberOf» -- Rebanho
```

- O rebanho é composto por animais que funcionam como membros do coletivo.

### Exemplo 4 — Administração pública
```
«Kind» Servidor Público
«Collective» Comissão
«Collective» Equipe Técnica

Servidor Público -- «MemberOf» -- Comissão
Servidor Público -- «MemberOf» -- Equipe Técnica
```

- O servidor pode ser membro de uma comissão ou equipe técnica.

## Resumo final

A relação «MemberOf» deve ser usada para representar a ligação entre um indivíduo membro e um coletivo. Ela é adequada para relações como Aluno–Turma, Veículo–Frota, Animal–Rebanho, Servidor–Comissão e Pessoa–Família. Não deve ser usada para partes funcionais, como Motor–Carro, nem para porções de matéria, como Água–Quantidade de Água.
