# Mapeamento do stereotypes UFO-L

| Estereótipo usado no modelo     | Mapeamento em OntoUML | 
| ------------------------------- | --------------------- | 
| `«Legal Agent»`                 | `«category»`          | 
| `«Legal RoleMixin»`             | `«rolemixin»`         | 
| `«Legal Role»`                  | `«role»`              | 
| `«Legal Relator»`               | `«relator»`           | 
| `«Legal Moment»`                | `«mode»`              | 
| `«Legal Event»`                 | `«event»`             | 

Mapeamento dos estereótipos conforme os conceitos da UFO-L, tais como «Legal Agent», 
«Legal RoleMixin», «Legal Relator», «Legal Moment» e «Legal Event», 
com o objetivo de tornar os diagramas mais expressivos para o domínio jurídico. 
Esses estereótipos são tratados como especializações semânticas dos estereótipos de OntoUML, 
conforme o mapeamento apresentado na tabela. Assim, «Legal Agent» corresponde a «category», 
«Legal RoleMixin» corresponde a «rolemixin», «Legal Relator» corresponde a «relator» e 
«Legal Moment» corresponde a «mode».
